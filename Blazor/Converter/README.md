# Converter

Проект решения `Blazor.sln` для задания «преобразование чисел из одной системы счисления в другую».

Тот же стек, что и в проекте `Blazor`: .NET 8, Blazor Web App, `@rendermode InteractiveServer`,
CSS-изоляцией (`*.razor.css`), Bootstrap из `wwwroot/bootstrap`.

## Что реализовано

Четыре пересчёта лежат одним классом в `Services/NumberConverter.cs` — имена методов совпадают
с пунктами задания:

| метод | что делает |
|---|---|
| `NumberConverter.Dec2Bin(string)` | десятичная → двоичная |
| `NumberConverter.Dec2Hex(string)` | десятичная → шестнадцатеричная |
| `NumberConverter.Bin2Dec(string)` | двоичная → десятичная |
| `NumberConverter.Hex2Dec(string)` | шестнадцатеричная → десятичная |

Внутри: `FromBase(...)` читает строку в `BigInteger` (с проверкой допустимых символов),
`ToString(...)` печатает число делением на основание. Работает с числами произвольной длины —
`long`/`int` не ограничивают.

Страница `/converter`:

* поле ввода + выбор направления (`Dec2Bin`, `Dec2Hex`, `Bin2Dec`, `Hex2Dec`), результат
  пересчитывается сразу (событие `oninput`), плюс кнопка «Конвертировать» и Enter в поле ввода;
* таблица проверки по разрядам: цифра × вес разряда, в конце — сумма (должна совпасть с числом);
* подсказка с результатом обратного чтения (результат читается обратно в своей системе и
  сравнивается с исходным числом);
* блок «все четыре функции на одном и том же числе»;
* некорректный ввод не роняет приложение — сообщение в `alert-danger`
  (например для `102` в двоичной системе).

Направление можно задать адресной строкой: `/converter?dir=hex2dec` (или `dec2bin`, `dec2hex`, `bin2dec`).

## Как запустить

```powershell
dotnet run --project Converter
# http://localhost:5161  (https: 7161) - порты в Converter/Properties/launchSettings.json
```

В меню проекта `Blazor` пункт **Converter** ведёт на `http://localhost:5161/converter`,
так как это отдельное приложение (как и `TODOlist`).
